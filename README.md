# To-Do List Application ✅

A simple and efficient To-Do List application developed using Python that helps users organize and manage their daily tasks easily. This application allows users to add, update, delete, and track tasks efficiently through a command-line or graphical user interface.

---

## 📌 Features

- Add new tasks
- View all tasks
- Update existing tasks
- Delete tasks
- Mark tasks as completed
- Simple and user-friendly interface
- Task management system

---

## 🛠️ Technologies Used

- Python
- Tkinter (GUI Version)
- File Handling / JSON
